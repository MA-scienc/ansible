# Impact explorer design

Review begins at the package boundary. The package column summarizes changed
and related files. The central pane expands one package or shows a directed
set of immediate file connections. The inspector keeps the diff and source
evidence available beside it. On phones the same panes stack in reading order.

The CSS variables in explorer.html are the source for interface colors.
Slate text and borders keep the report quiet, teal marks current selection,
and status labels pair explicit text with amber, green, red, and blue.
Source paths and code use a monospace stack. All controls work offline
and remain accessible through native keyboard navigation.
